# mantis-react-ts [vite]

Web theme with name as 'Mantis'. Its name of insect but we derived it from two popular UI framework, Material-UI and Ant Design (M-Ant-is). It provides best features from each. Follows design principle of AntDesign and uses the Component of Material-UI.

## Locally

`npm install --global --force yarn` <br />
`corepack enable` <br />
`yarn set version 4.9.1` <br />
`yarn install` <br />
`yarn run start` <br />

## Docker

**Change 'NODE_ENV' inside 'IpceiDigitFront.env':**

'NODE_ENV=development' - uses '.env.development' <br />
'NODE_ENV=production' - uses '.env.production' <br />

`docker compose up`

## Tests

`yarn run test`

If you have slow performance running tests inside Docker container, complete installation step and run tests locally.
